# chartworks/issues

Issue tracker for [Chartworks](https://chartworks.dev) — chart rendering for AI agents.

## Scope

File issues here for:

- The `chartworks` CLI ([npm](https://www.npmjs.com/package/chartworks))
- The Chartworks MCP server
- The web app and playground at chartworks.dev
- Chart rendering correctness / spec validation
- Documentation gaps

The agent-skill has its own tracker too: [chartworks/skill/issues](https://github.com/chartworks/skill/issues). Either repo is fine for skill-related reports.

## Filing a good issue

Include:

- What you ran (CLI command, MCP tool call, the spec JSON).
- What you expected.
- What happened — error output verbatim, screenshot if it's a visual issue.
- Version: `npx chartworks --version` (CLI), or your MCP client name/version.

For chart-correctness issues, share the **minimal spec that reproduces**.
